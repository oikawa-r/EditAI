# アプリケーション全体設計（UI要件）

デスクトップアプリの画面は2つ。起動時のプロジェクト管理と、編集用のメインワークスペース。多機能なメニューは置かず、次にやることが画面から分かるようにする。

この文書は画面と機能の要件を書く。ここにある要件は、実装の正とする。

アプリ全体の UI テーマは、ダークモードを基準とする。背景、パネル、文字色は暗い色で統一し、映像と操作対象が背景から浮かんで見えるようにする。

起動時に開発用の動画を自動で読み込んだり、タイムラインへ自動で置いたりしない。編集画面は、素材もクリップも空の状態で開く。

## 状態管理要件

編集中の状態は、ペインごとのローカル変数に分けない。アプリ全体で1つのグローバルステートに置き、すべてのペインはこれを読んで描画する。変更するときも、先にこのステートを更新し、その結果を各ペインへ反映する。

タイムラインの中身は、このステート内のプロジェクトデータを単一の情報源（Single Source of Truth）とする。プレビュー用のコピーや、ツールペイン専用のクリップ情報は持たない。

### プロジェクトデータ

プロジェクトデータは、トラックの配列と、各トラックが持つクリップの配列で表す。

```text
プロジェクト
├─ 解像度（width, height）  例: 1920 x 1080
├─ フレームレート（fps）
├─ アスペクト比
└─ トラックの配列
   └─ クリップの配列
      ├─ id
      ├─ type            動画 / 画像 / 音声 / テロップ
      ├─ startTime       トラック上の開始時刻（秒）
      ├─ duration        タイムライン上の長さ（秒）
      ├─ speed           そのクリップだけの再生速度（1 が等速）
      ├─ sourceUrl       元ファイルの場所（テロップは空でもよい）
      └─ 表示プロパティ   座標（x, y）、スケール、幅、高さ、回転 など
```

- タイムライン、プレビュー、プロパティ編集は、この階層だけを見てクリップを描く。
- クリップの追加、移動、長さの変更、分割、削除、サブ画面からの反映は、この配列を直接更新する。別構造へ変換してから表示しない。
- 解像度、フレームレート、アスペクト比も同じプロジェクトデータに保持する。キャンバスの大きさ、コマ送り、書き出しは、ここに書いた値を使う。
- `duration` は、タイムライン上でそのクリップが占める秒数である。スピードを変えると、この長さが反比例して変わる。詳細は「スピードとクリップ長」を参照。

### 再生位置と選択

プロジェクトデータと並べて、次も同じグローバルステートで一元管理する。

- **currentTime** — タイムラインの現在時刻（秒）。タイムラインの再生ヘッドと、タイムラインプレビュー中のモニターは、この値を見て位置を決める。
- **selectedClipIds** — タイムラインで選択中のクリップ ID の配列。何も選んでいないときは空にする。1件のときだけ、プロパティ編集とプレビューの枠をそのクリップに出す。
- **selectedMediaId** — 素材ペインで選択中の素材 ID。何も選んでいないときは空にする。
- **previewTarget** — プレビューが今どちらを映しているか。`media`（素材そのもの）または `timeline`（再生ヘッドの時刻）のどちらか。

プレビューの切り替え規則は次のとおり。最後に選んだ方が、モニターの表示対象になる。

- 素材一覧のアイテムを選ぶと、`previewTarget` を `media` にし、その素材の映像・画像・音声をモニターに出す。タイムラインの再生ヘッドは動かさない。
- タイムライン上のクリップを選ぶと、`previewTarget` を `timeline` にし、再生ヘッドがある時刻の映像をモニターに出す。

プロパティ編集とプレビューの枠は、`selectedClipIds` が1件のときのクリップを対象にする。複数選んでいるときは、プロパティ編集を隠し、プレビューの枠は出さない。削除は、選んでいるクリップをまとめて外す。素材を選んだだけでは、プロパティ編集は開かない。分割は、再生ヘッドの時刻に選択中のクリップが1つでもあるときはその選択クリップだけを切る。選択が無いとき、および選択中クリップが再生ヘッドの外にあるときは、その時刻に重なるすべてのトラックのクリップを切る。再生ヘッド上にクリップが無いときは切らない。

### 直接操作とプロパティ編集の同期

モニター上の直接操作（ドラッグでの移動、ハンドルでの拡大・縮小・回転）と、ツールペインのプロパティ編集は、どちらも上記のクリップデータを直接更新する。

- キャンバスで動かした直後に、そのクリップの座標・スケール・回転をプロジェクトデータへ書き、プロパティ編集の数値とスライダーも同じ値に更新する。
- プロパティ編集で数値またはスライダーを変えた直後に、同じクリップデータを書き、プレビューの枠と映像も同じ値に更新する。
- どちらも確定ボタンを待たない。操作の途中から、プレビューと数値はリアルタイムで一致させる。
- 対象は、選択中の画像・テロップ・動画クリップである。

### 操作の取り消し

プロジェクトデータのステートは、現在の1面だけでなく、過去の履歴を保持できる形にする。タイムラインの「元に戻す」は、この履歴を1つ前のプロジェクトデータへ戻す。戻したあとも、各ペインは同じグローバルステートを読んで再描画する。再生ヘッドを動かしただけでは履歴に積まない。

## 画面1: プロジェクト管理画面（スタート画面）

アプリ起動時に表示する。新規作成と、過去のプロジェクトの続きから、のどちらかを選ぶ。サンプル動画の自動読み込みはしない。

### ヘッダー

- シンプルなロゴ
- 設定ボタン

### メインエリア

- 大きく目立つ「＋ 新しいプロジェクトを作成」ボタン
- その下に「プロジェクトを開く（続きから）」。保存した `.editai` を選んで、編集画面へ戻る
- その下に、最近開いたプロジェクトをサムネイル付きのカードで並べる。カードは見本で、ファイルは開かない

迷わず「作る」か「続きから」かを選べるようにする。

新規作成のとき、プロジェクトの解像度（例: 1920x1080）とフレームレート（fps）を決める。決めた値はプロジェクトデータに保持し、編集画面のキャンバスと書き出しで使う。作成した直後の編集画面には、素材もクリップも無い。

## プロジェクトファイル（.editai）

編集中の状態を、拡張子 `.editai` の JSON ファイルに保存し、あとから開き直す。保存と読み込みはデスクトップアプリのダイアログとファイル読み書きで行う。

### 保存

編集画面ヘッダーの「プロジェクトを保存」で、保存ダイアログを開く。初期のファイル名は、いま開いている `.editai` があればそのパス、無ければヘッダーのプロジェクト名に `.editai` を付けたものにする。選んだパスへ、次の内容を UTF-8 の JSON で書く。

ブラウザでこの画面を単独で開いたときは、Tauri の API を呼べない。保存と読み込みは無効にし、デスクトップアプリで使う旨を知らせる。

| キー | 内容 |
|---|---|
| `version` | ファイル形式。いまは `1` |
| `savedAt` | 保存した日時（ISO 8601） |
| `name` | ヘッダーに出しているプロジェクト名 |
| `project` | 解像度、fps、トラックとクリップ。`blob:` のプレビュー URL は空にする |
| `media` | 素材の id、名前、種類、ファイルパス、長さ。プレビュー用 URL は書かない |
| `style` | テロップのスタイル |
| `segments` | 解析で得たテロップ区間 |
| `threshold` | 重要度の表示しきい値 |
| `currentTime` | 再生ヘッドの時刻（秒） |
| `selectedClipIds` | 選択中のクリップ ID の配列。1件のときは `selectedClipId` にも同じ ID を書く |
| `selectedMediaId` | 選択中の素材 |

アプリ全体のスタイルプリセットと、バックエンドの解析ジョブ（書き出しに使う結果）はファイルに入れない。保存後、ヘッダーの名前は選んだファイル名（拡張子を除く）に合わせる。

### 読み込み

スタート画面の「プロジェクトを開く（続きから）」で `.editai` を選ぶ。`version` が `1` で、`project.tracks` があるものだけを受け付ける。それ以外は、プロジェクトファイルではない旨を知らせて画面は変えない。

復元するものは、`project`、`media`、`style`、`segments`、`threshold`、`currentTime`、選択中のクリップと素材。スタイルは、ファイルに無い項目を既定値で補う。読み込んだあとは編集画面へ移し、素材一覧、タイムライン、プレビュー、スタイル、プロパティを描き直す。取り消し履歴は、開いた直後の状態を最初の1手にする。

素材の `path` からプレビュー用 URL を作り直す。ファイルが無い、またはそのパスをプレビューに使えないときは、素材の項目は残し、URL だけ空にする。クリップの `sourcePath` も同じ対応で、プレビュー URL を付け直す。見つからなかったメディアファイルの名前は、最大3件までトーストで警告する。それ以上あるときは、名前を増やさず件数だけ足す。

解析ジョブの結果は復元しない。開いた直後の書き出しは、あらためて解析が終わるまで押せない。

## 画面2: メイン編集画面

動画のインポート、編集、プレビューを行うワークスペース。

### ヘッダー

- 左にロゴ、中央にいま開いているプロジェクト名を置く。保存したファイルを開いたときは、ファイルに書いた名前を出す。
- 「プロジェクトを保存」を置く。押すと保存ダイアログが開き、いまの編集内容を `.editai` に書く。
- 右端に「動画を書き出す」ボタンを置く。押すと、編集結果を1本の動画ファイルとして書き出す。
- 設定ボタンを置く。押すと「プロジェクト設定」を開く。解像度、フレームレート、アスペクト比を変えて OK すると、プロジェクトデータとプレビューへ反映する。中身は、プレビューの「カスタム」から開くものと同じダイアログにする。

### 全体レイアウト

上段の初期列比は 3:1:6（素材・ツール・プレビュー）にする。素材とツール、ツールとプレビューの境目は、カーソルを合わせると左右矢印になり、ドラッグで隣接するペインの幅を変えられる。各ペインには最小幅を置き、それより狭くはしない。下段のタイムラインは、上段の3列すべてにまたがり、横幅いっぱい（100%）にする。縦の境目でタイムラインの高さだけは変えられる。

- 上段（左から）: 素材 30%、ツール 10%、プレビュー 60%
- 下段: タイムライン。横幅いっぱい（100%）

| 位置 | 画面上の名前 | 役割 |
|---|---|---|
| 左上（30%） | 素材 | 動画・画像・音声のインポートと管理 |
| 中央（10%） | ツール | カットとテロップ。クリップを選ぶとプロパティ編集も出る |
| 右上（60%） | プレビュー | 素材、または再生ヘッド時刻の確認 |
| 下部（100%） | タイムライン | 場面の順番や長さの操作 |

### 左ペイン: 素材

動画、写真、音声をインポートし、管理する領域。

- 「追加する」からファイルを選ぶ。複数選べる。動画、音声、画像を対象にする。
- このペインへファイルをドロップしても、同じように素材へ追加する。
- 追加しただけでは、無音解析も切り込みも走らない。タイムラインへは置かない。素材の一覧だけが増える。
- 一覧はサムネイルのカードを格子状に並べる。ファイル名と種類は、サムネイルの下端に半透明の帯で重ねる。動画のカードは、サムネイルの右下に全体の長さを `00:00:34` の形で出す。その素材がタイムラインで1回以上使われているときは、サムネイルの左下にチェックを出す。
- カードの右上には「＋」を常に出す。押すと、その素材のクリップを再生ヘッドの時刻へ置く。置く先は、種類が合うトラックのうち、その時間帯が空いているいちばん上のトラック。空いていなければ、映像は一番上に、音声は一番下に、トラックを1本足してそこへ置く。
- 一覧のアイテムをクリックすると、その素材を選択し、プレビューモニターにはその素材自体を出す。動画と音声は、そのファイルを頭から再生できる。画像はその静止画を出す。
- 一覧のアイテムは、マウスのボタンを押したまま数ピクセル動かすとドラッグが始まる。掴んでいるあいだは、カードのコピーがマウスに付いて動き、カーソルは掴んでいる形になる。ブラウザのドラッグ禁止マークは出さない。タイムラインの上へ来ると、置くトラックと時刻と長さが半透明の枠で見える。タイムラインの上で離すと、その位置にクリップとして置ける。タイムラインの外で離したときは置かない。同じ素材は、何度でもドラッグして、別の時刻や別のトラックへ重ねて置ける。既存のレーンの上で離したときは、そのトラックの、離した時刻に置く。動画と画像は映像トラック、音声は音声トラックだけに置ける。種類が違うレーンで離したときは置かず、置けない旨を知らせる。レーンの外（映像のさらに上、音声のさらに下）で離したときは、トラックを1本足してそこに置く。放した時刻が `startTime` になる。長さは、その素材の尺（画像は既定の秒数）とする。「＋」から置いたときも、長さは同じ尺にする。

### 中央ペイン: ツール

カットとテロップは、タブで切り替えない。サブタイトルとして常に両方を縦に表示し、その中のボタンも横ではなく縦に並べる。

ボタンは、選んでいるクリップの種類が次の条件に合うときだけ押せる。それ以外は無効にし、グレーアウトする。解析中も押せない。

- **無音部分に切り込みを入れる、カット一括削除選択** — 動画クリップが1件以上選ばれているとき。複数選んでいるときは、その動画クリップそれぞれの範囲へ同じ処理を行う。
- **テロップ生成** — 動画クリップが1件以上選ばれているとき。複数選んでいるときは、その動画クリップたちの範囲を対象にする。
- **テロップ編集** — テロップまたは動画が1件以上選ばれているとき。対象は、選んだ各クリップの `startTime` から `duration` までである。

```text
ツール
├─ カット
│  ├─ 無音部分に切り込みを入れる
│  └─ カット一括削除選択
└─ テロップ
   ├─ テロップ生成  ［歯車］
   └─ テロップ編集
```

- **カット**
  - **無音部分に切り込みを入れる** — メイン画面のまま実行する。動画クリップを選択し、このボタンを押したときだけ、無音解析と切り込みを行う。リクエストは無音区間の把握だけにし、文字起こしと LLM は送らない。対象は、選択中の各クリップの、トリミング後の `startTime` から `duration` までだけである。同じ素材の、選んでいない区間は切らない。選択中クリップの無音部分を検出し、削除はせず、切り込み（スプリット）だけを入れる。音のある区間と間が分かれる。素材のインポート時、およびボタンを押していない間は、解析しない。
  - **カット一括削除選択** — 専用サブ画面を開く。無音を詰めた版と、切り込みだけの版を上下で見比べてから、どちらかをメインタイムラインへ戻す。画面の詳細は「専用サブ編集画面」を参照。無音の結果がまだ無いときは、先に無音解析だけを実行し、終わってから比較画面を開く。
- **テロップ**
  - **テロップ生成** — 専用サブ画面を開く。ボタンの横の歯車で、生成前の条件を決める。文字起こしがまだ無いときは、文字起こしとテロップ用の LLM だけをリクエストし、無音検出は送らない。終わってから画面を開く。渡す文字起こしは、選んだ動画クリップの範囲（トリミング後の `startTime` から `duration` まで。複数選択ならその和）に完全に入るか、重なる部分だけにする。返ってきた各文は、歯車で決めた文字数の近くの句読点や空白で分け、その長さのテロップにする。
    - **歯車** — ツールペイン上のボタン横に置く。押すと「何文字を目安にテロップを生成する」を決められる。サブ画面は開かない。既定は 20 文字。
  - **テロップ編集** — 専用サブ画面を開く。フォントやプリセットの適用は、この画面で行う。リストに出すテロップは、選んだクリップの時間範囲と重なるものだけにする。動画全体や、同じトラックの全テロップは対象にしない。

#### クリップ選択時: プロパティ編集

タイムラインで動画、画像、またはテロップのクリップを1件だけ選ぶと、ツールペインに「プロパティ編集」が追加で表示される。選択を外したとき、または複数選んでいるときは隠れる。音量やフェードは動画のときだけ出す。テロップを選んだときは、いちばん上にテキスト欄を出す。プレビュー上の文字と、この欄は、入力のたびに同じ文章になる。カットとテロップのサブタイトルは、これまでどおり常に表示する。対象は、`selectedClipIds` が1件のときのクリップだけにする。

数値の変更は、確定ボタンを待たずにリアルタイムで反映する。数値入力とスライダーのどちらを動かしても、グローバルステート上のそのクリップを直接更新し、もう片方のコントロールとプレビューも同じ値に揃える。キャンバス上のドラッグや拡縮でも、同じクリップデータが書き換わり、数値とスライダーが追従する。

各項目は、数値入力を残したまま、横方向のスライダーを並べる。スライダーを付ける項目は次のとおり。

- スケール（%）
- 幅（px）
- 高さ（px）
- X座標
- Y座標
- スピード
- 音量
- フェードイン（秒）
- フェードアウト（秒）
- ピッチ（半音）

回転角度は数値入力のままとする。反転とクロマキーは、ボタンとチェック、色の選択のままとする。

画像と動画で共通の項目と、動画を選んだときだけ出る項目に分ける。

**共通設定（画像・動画）**

- **反転・回転** — 水平反転、垂直反転（逆さま）、90度回転のボタン。回転角度（度）は数値で指定する。
- **変形（トランスフォーム）** — スケール（％）、幅（px）、高さ（px）。それぞれ数値とスライダー。
- **位置** — X座標、Y座標。それぞれ数値とスライダー。
- **クロマキー合成** — 色を選び、その色をプレビュー上で透過させる。オンのあいだ、そのクリップが再生ヘッドの下にあるとき、指定色に近いピクセルを抜く。
- **スピード** — そのクリップだけの再生速度（例: 0.5倍、2倍）。数値とスライダー。プレビュー全体の速度は変えない。変えた結果、タイムライン上のクリップの長さが反比例して変わる。

**動画専用設定（動画クリップを選んだときだけ表示）**

- **オーディオ** — 音量（0〜200%。既定は 100。100 が原音）、フェードイン時間（秒）、フェードアウト時間（秒）。それぞれ数値とスライダー。
- **音声エフェクト** — ピッチ（半音）。数値とスライダー。再生速度は変えず、プレビューの音の高さだけが変わる。書き出しでは、FFmpeg の `rubberband` が使える環境ではそれを使う。使えない環境では、`asetrate` と `atempo` を組み合わせ、長さを維持したまま音程を変える。

#### スピードとクリップ長

スピードは、プロジェクト全体やプレビューの再生ボタンの速度ではない。選んだクリップだけに掛かる。

- 等速を 1 とする。2 は2倍速、0.5 は半分の速度である。
- タイムライン上の `duration` は、スピードを掛けたあとの見た目の長さである。スピードを変えると、`duration` は反比例して縮む、または伸びる。
- 例: タイムライン上で 10 秒のクリップを 2 倍速にすると、長さは 5 秒になる。0.5 倍速にすると、長さは 20 秒になる。
- 計算は、変更前の長さに「変更前のスピード ÷ 変更後のスピード」を掛ける。
- そのクリップを再生しているあいだ、モニターはそのスピードで進む。他のクリップや、再生ヘッドがクリップの外にあるときの進み方は変えない。
- 端をドラッグして長さを変えたあとも、いまのスピードは維持する。そのときの `duration` が、次にスピードを変えるときの基準になる。

### 右上: プレビューモニター

再生の確認と、選択中クリップの位置・大きさ・回転の調整を行う。ペインは上下に分ける。上側がキャンバス、下側が操作バー。

```text
┌─────────────────────────────────────────┐
│                                         │
│  メインモニター（黒背景のキャンバス）      │
│                                         │
├─────────────────────────────────────────┤
│ |< 再生 >|  ═══════  00:00:34 / 00:01:10 │
│                     16:9  音 写真 全画面 │
└─────────────────────────────────────────┘
```

| 領域 | 役割 |
|---|---|
| メインモニター | 動画、画像、テロップを描くキャンバス |
| コントロールバー | 再生、シーク、時間、画面比率、音量、保存、全画面 |

#### 何を映すか

モニターの中身は `previewTarget` で決まる。

- **素材を選んでいるとき（`media`）** — 左ペインで選んだ素材そのものを出す。動画はそのファイルを再生する。画像はその静止画を出す。音声はそのファイルを再生する。タイムラインの重なりや、クリップの座標・スケールは掛けない。
- **タイムラインを見ているとき（`timeline`）** — 再生ヘッド（赤線）がある時刻の映像を出す。その時刻に重なるクリップを、トラックの前後関係に従って描く。画像とテロップは映像の上に重ねる。クリップを選んでも、モニターの映像をそのクリップだけに切り替えない。選択はプロパティ編集と、プレビュー上の枠・直接操作にだけ使う。

タイムライン側で再生ヘッドを動かすと、`timeline` のときだけモニターの時刻が追従する。`media` のあいだは、素材側の再生位置を動かし、タイムラインの赤線は動かさない。

#### メインモニター領域

ペインの上部、大半をこの領域にする。

- 背景は黒、またはそれに近い暗い色にする。映像との境界が分かるようにする。
- キャンバスの縦横比は、プロジェクトのアスペクト比に従う。モニター領域よりキャンバスが小さいときは、領域の中央に置き、余白は暗い背景のままにする。

#### モニター上の直接操作

選択中のクリップ（画像、テロップ、動画）は、別の設定パネルを開かずに、キャンバス上で触って動かせる。移動・拡縮・回転の結果は、ツールペインの数値とは別に持たず、グローバルステートのクリップデータへ直接書き込む。プロパティ編集の数値とスライダーは、その場で同じ値に更新する。

この操作が出るのは、タイムラインでクリップを選んでいて、モニターが `timeline` のときである。

- **選択** — キャンバス上の画像、テロップ、動画をクリックすると、そのクリップが選択される。キャンバスの何もないところをクリックすると、選択を外す。
- **位置の移動** — 選択したクリップをドラッグして、キャンバス内の好きな位置へ動かす。動かした分は、そのクリップの X / Y になる。
- **サイズの拡縮** — 選択中だけ、クリップの周囲に枠（バウンディングボックス）と四隅のハンドルを出す。四隅のハンドルをドラッグすると、縦横比を保ったまま拡大・縮小する。結果はスケール、幅、高さに反映する。テロップのときは、その拡大・縮小の割合と同じ割合で `style.font_size` も変える。枠とハンドルは、動画の再生面などに操作を奪われないよう、常に最前面（前面レイヤー。z-index を最大）に置く。
- **テロップの文字** — プレビュー上のテロップをダブルクリックすると、その場で文字を編集できる。クリックしただけでは移動は始まらず、数ピクセル以上動かしたときだけドラッグになる。`Shift + Enter` で改行する。入力中の文字は、プロパティ編集のテキスト欄とすぐ揃う。入力を終えてフォーカスが外れると、その文章をクリップの `text` に保存し、プレビューとタイムラインの表示を更新する。
- **回転** — 枠の外に回転用のハンドルを置く。ドラッグすると、クリップの中心を軸に回転する。結果は回転角度になる。
- **スナップ線** — 移動中、キャンバスの中央（縦・横）や、他の要素の端・中央に近づくと、一時的なガイドラインを表示して吸着する。手を離すとガイドは消える。

#### コントロールバー

モニターの直下に、横一列で置く。左から次の順にする。

1. **再生コントロール** — 「コマ戻し」「再生 / 一時停止」「コマ送り」。文字ではなくアイコンで示す。再生中は一時停止のアイコンに切り替える。入力欄にフォーカスがあるときを除き、`Space` で再生と一時停止を切り替える。同じ条件で、左矢印は1コマ戻し、右矢印は1コマ送りにする。タイムラインの横スクロールには使わない。
2. **プレビュー用シークバー** — 今映している対象の再生位置。
3. **時間表示** — `00:00:34 / 00:01:10` のように、「現在時間 / 全体時間」をテキストで出す。
4. **アスペクト比** — キャンバス比率のドロップダウン。
5. **ユーティリティ** — 右端に、音量、スクリーンショット、全画面のアイコンを置く。

**再生コントロール**

- **コマ戻し** — 一時停止し、1フレーム前へ移動する。フレーム長はプロジェクトの fps に従う。
- **再生 / 一時停止** — 再生中は一時停止、止まっているときは再生する。ボタンは再生の三角と、一時停止の二本線を切り替える。編集画面で `Space` を押したときも同じ切り替えを行う。文字入力、数値、選択リストにフォーカスがあるときは、`Space` では再生を変えない。
- **コマ送り** — 一時停止し、1フレーム先へ移動する。右矢印キーでも同じ動きにする。
- **コマ戻し** — 一時停止し、1フレーム前へ移動する。左矢印キーでも同じ動きにする。

`timeline` のときは、これらの操作が `currentTime` と再生ヘッドを動かす。`media` のときは、選んでいる素材の再生位置だけを動かす。

**シークバー**

- バーの上をドラッグして、今映している対象の再生位置を移動する。
- `timeline` のときは、離した位置の時刻でタイムラインの再生ヘッドも動く。タイムライン側で再生ヘッドを動かしたときも、このバーが同じ割合に追従する。
- タイムラインでクリップを移動またはトリミングしている間は、映像をシークしない。ドラッグを始めたときの画面を維持し、手を離して位置が確定してから、その時刻へ合わせる。

**時間表示**

- 時・分・秒を `00:00:00` の形で、現在時間と全体時間を並べる。
- `timeline` の全体時間は、スクロールできる時間範囲の終わりではなく、タイムライン上の最終クリップの終わりまでとする。クリップが無いときは 0 とする。
- `media` の全体時間は、その素材の尺とする。画像は、タイムラインへ置いたときの既定の長さに合わせる。

**アスペクト比メニュー**

プロジェクト全体のキャンバス比率を変える。選択肢は次のとおり。

- 16:9（横型）
- 9:16（縦型）
- 4:3
- 3:4
- 1:1
- カスタム

16:9、9:16、4:3、3:4、1:1 を選ぶと、その比率をすぐプロジェクトとプレビューへ適用する。解像度のピクセル数は、いまの幅または高さを基準に、選んだ比率へ揃える。

**カスタムを選んだとき**

ドロップダウンで「カスタム」を選ぶと、その場では比率を確定しない。「プロジェクト設定」のモーダルダイアログを開く。

ダイアログでは、次を選択または手入力する。

- アスペクト比（上の定形、または幅と高さから決まる自由比率）
- 解像度（幅と高さ、ピクセル）
- フレームレート（fps）

「OK」で、入力した値をプロジェクトデータへ書き、プレビューのキャンバスとコマ送りへ適用してダイアログを閉じる。「キャンセル」やダイアログを閉じただけでは、開く前の解像度、fps、アスペクト比のままにする。ヘッダーの設定ボタンも、同じダイアログを開く。

**右端のアイコン**

- **音量** — アイコンを押すと、プレビューのミュートを切り替える。ミュート中は、アイコンの見た目で消音だと分かるようにする。アイコンの上には、プレビュー全体の音量を 0〜100 で変える縦のスライダーを出す。アイコンからスライダーへマウスを移しても、あいだでポップアップが消えないようにする。スライダーを動かすと、その場でプレビューの音量に反映する。クリップごとの音量とは別に持つ。
- **スクリーンショット** — カメラのアイコン。押すと、いまモニターに出ているフレームを画像として保存する。クロマキーで抜いた絵が出ているときは、抜いたあとの絵を保存する。保存した画像は、素材ペインへ写真として追加し、タイムラインへドラッグして置ける。
- **全画面** — モニター領域を画面いっぱいに広げる。操作バーも残す。もう一度押すと、元のペインに戻る。

### 下部: タイムライン（シーケンスバー）

トラック型のシーケンスバーにする。時間は左から右へ進む。クリップの選択、移動、長さの変更、分割は、このエリアで行う。

```text
┌──────────────────────────────────────────────────────────┐
│ 上部ツールバー     分割 削除 クロップ 元に戻す テキスト マイク ［ズーム］ │
├──────────────┬───────────────────────────────────────────┤
│              │ タイムルーラー（00:00 と目盛り）            │
│              │            ■ 再生ヘッド（赤）              │
│ トラック     ├───────────────────────────────────────────┤
│ ヘッダー     │ トラックエリア（クリップが並ぶ）            │
│ （固定幅）   │  赤線はトラックの上から下まで貫く           │
│              │                                 │縦スクロール│
│              ├─────────────────────────────────┴──────────┤
│              │ 横スクロール（右の空の時間へも進める）      │
└──────────────┴────────────────────────────────────────────┘
```

領域は次の4つ。ルーラーとトラックエリアは横に同期してスクロールする。トラックヘッダーは横スクロールでは動かない。

| 領域 | 役割 |
|---|---|
| 上部ツールバー | 編集コマンドと、時間軸のズーム |
| タイムルーラー | 時刻の目盛り。再生ヘッドの赤い四角を置く |
| トラックヘッダー | 各トラックの表示やロック。左端に固定 |
| トラックエリア | クリップを置く、スクロールできる本体 |

#### 上部ツールバー

左にツール、右端にズームスライダーを置く。テキストとマイクはズームの左に、テキスト、マイクの順で置く。

- **分割** — 再生ヘッドの位置でクリップを切る。ハサミと同じ結果にする。キーボードの `S` でも実行する。再生ヘッドの時刻に選択中のクリップがあるときは、その選択クリップだけを切る。選択が無いとき、および選んでいるクリップが再生ヘッドの外にあるときは、再生ヘッドに重なるすべてのトラックのクリップを切る。再生ヘッド上にクリップが無いときは切らない。ロック中のトラックは切らない。
- **削除** — 選択中のクリップをトラックから外す。複数選んでいるときは、その全部を外す。キーボードの `Delete` または `Backspace` でも実行する。ロック中のトラックでは削除しない。
- **コピーと貼り付け** — クリップを選んだ状態で、`Ctrl + C`（Mac は `Cmd + C`）がそのクリップを記憶する。複数選んでいるときは、間隔を保ったまままとめて記憶する。`Ctrl + V`（Mac は `Cmd + V`）は、再生ヘッドの位置へ、同じトラックに置く。重なった部分は、貼り付けたクリップを残して上書きする。`Shift + D` は、記憶を変えずに、再生ヘッドの位置へ複製する。文字を入力しているあいだは、コピーと貼り付けと複製は、その入力欄に任せる。`Ctrl + S`（Mac は `Cmd + S`）は、入力中でもプロジェクトの保存を開く。カット比較とテロップ生成のタイムラインでも、その画面で選んでいるクリップに同じ操作が効く。
- **クロップ** — 動画または画像のクリップが1件だけ選ばれているときだけ押せる。音声やテロップ、未選択のときは押せない。押すと専用画面が開く。左でアスペクト比（16:9、4:3、1:1、9:16、カスタム）を選び、右の映像の上で枠を動かしたり四隅で大きさを変える。決定すると、その範囲を `cropX`、`cropY`、`cropWidth`、`cropHeight`、`cropAspect` として、そのクリップだけへ書く。同じ素材から分けた別のクリップには広がらない。メインのプレビューは、見えているクリップ自身の範囲だけを切り抜く。書き出しの映像への反映は、まだ行わない。
- **元に戻す** — プロジェクトデータの履歴を1つ前へ戻し、各ペインを再描画する。やり直しも対で持つ。
- **テキスト** — 再生ヘッドの位置を開始時刻にして、`type: "テロップ"` のクリップを置く。表示は「新しいテキスト」。置く先は、対象の動画クリップのすぐ上の映像トラックである。対象は、選択中の動画クリップ。動画を選んでいないときは、再生ヘッドと重なるいちばん上の動画クリップ。そのすぐ上のトラックが無いとき、ロックされているとき、または同じ時間にクリップがあるときは、対象の動画のすぐ上に新しい映像トラックを作ってそこへ置く。動画のトラックや、それより下のクリップは上書きしない。対象の動画が無いときは、一番上に新しい映像トラックを足す。初期の枠は、文字数と文字サイズから幅と高さを決める。置いたクリップは選択状態にし、プロパティ編集とプレビュー上の直接操作ができる。
- **マイク** — その場でナレーションを録音する。押すと録音を始め、もう一度押すと止まる。止めた音声は、そのときの再生ヘッドの位置から、音声クリップとして音声トラックへ置く。
- **ズームスライダー** — 右端。時間軸の表示倍率を変える。左が縮小、右が拡大。

#### タイムルーラー（上部メモリ）

- `00:00` のようなタイムコードと、その間の細かい目盛りを表示する。
- 目盛りの間隔は、ズーム倍率に合わせて変える。拡大しているときは秒以下、縮小しているときは十秒や分単位でも読めるようにする。
- ルーラーの目盛り部分をクリックすると、その時刻へ再生ヘッドが移動する。`previewTarget` が `timeline` のとき、プレビューの表示時刻も同じ位置に揃える。

#### 再生ヘッド

現在のタイムライン時刻を、ルーラーからトラックエリアの一番下まで貫く細い赤い縦線で示す。線の太さは 2px で、指している時刻が線の中央になる。トラックエリア側の線の上には、クリックできるハサミを置く。マウスを近づけただけではハサミは動かない。赤い線の、ハサミ以外の場所をドラッグして再生位置を動かしても、ハサミの高さは変わらない。ハサミ自体を上下にドラッグしたときだけ高さが変わり、その高さを覚えて、タイムラインを描き直しても同じ高さに戻す。ホバーすると色が変わり、押せることを示す。ルーラー上の赤い四角も残す。

ハサミと、ルーラー上の赤い四角の操作は、次で分ける。

- **ハサミの左クリック** — 押して、ほとんど動かさずに離したときは、その位置でクリップを分割する。赤い線の、ハサミ以外の場所をクリックしても分割しない。再生ヘッドの時刻にクリップが無いときは切らない。再生ヘッドの時刻に選択中のクリップがあるときは、その選択クリップだけを切る。選択が無いとき、および選んでいるクリップが再生ヘッドの外にあるときは、再生ヘッドに重なるすべてのトラックのクリップを同時に切る。ロック中のトラックは切らない。切った後半は、タイムライン上の開始時刻に加え、素材内の開始位置（`sourceStart`）も引き継ぐ。速度が 1 でないときは、タイムライン上の経過に速度を掛けた分だけ素材位置を進める。
- **長押し（ドラッグ）** — ハサミ、赤い線、ルーラー上の赤い四角を押したまま左右へ動かすと、再生ヘッドを移動する（シーク）。ハサミの高さは、ハサミ自体をドラッグしているときだけマウスに付いて変わる。赤い線のほかの場所では、横へ動かしても高さは変わらない。離した時刻が `currentTime` になる。短くクリックしただけではシークしない。手を離すと、表示はハサミに戻る。覚えた高さは、分割や選択のあとの描き直しでも残る。

再生ヘッドを動かす操作は、ルーラーのクリックとドラッグ、および再生ヘッド（赤い線と赤い四角）のドラッグに限る。トラックの空き領域を左クリックして選択を外すとき、および矩形選択のドラッグでは、再生ヘッドは動かさない。クリップの本体をドラッグしたときは移動、左右の端をドラッグしたときはトリミングであり、シークにはしない。

#### トラックヘッダー（左サイドコントロール）

各トラックの左端に、固定幅のヘッダーを置く。トラックの種類でアイコンを変える。どちらもトグルで、押すたびにオンとオフが入れ替わる。

- **映像トラック** — 「目玉」（表示 / 非表示）、「スピーカー」（ミュート）、「鍵」（編集ロック）。非表示のトラックはプレビューに出さない。ミュート中は、その映像の音を出さない。ロック中のトラックは、移動・トリミング・分割・削除を受け付けない。
- **音声トラック** — 「スピーカー」（ミュート）と「鍵」（編集ロック）。ミュート中は音を出さない。

ヘッダーの名前の部分を上下にドラッグすると、同じ種類のトラックの並びを入れ替えられる。映像は映像の中、音声は音声の中だけで動かし、種類をまたいでは入れ替えない。トラックの中のクリップは、そのトラックに付いたまま一緒に動く。目玉・スピーカー・鍵のボタンを押したときは並べ替えない。離した位置が元と同じなら、何も変えない。

入れ替えが終わったら、位置に合わせて名前を付け直して描き直す。映像は一番下を「映像 1」とし、上へ向かって番号を増やす。音声は一番上を「音声 1」とし、下へ向かって番号を増やす。

**初期表示**

最初から出すトラックは、次の4本に固定する。空のトラックを、これ以上は最初から並べない。配列の先頭が画面の一番上で、この順のまま描く。

- 映像 3
- 映像 2
- 映像 1
- 音声 1

映像トラックは上が手前（重なりの上）になる並びにする。番号は、タイムラインの下から上へ 映像 1、映像 2、映像 3 と増える。いちばん下の映像が映像 1、いちばん上が映像 3 である。音声トラックは、映像トラックの下に置く。番号は、上から下へ 音声 1、音声 2 と増える。あとから足す映像トラックは、いま一番上の映像より上へ置き、番号はいまの最大より 1 大きい。音声トラックは、いま一番下の音声より下へ置き、番号はいまの最大より 1 大きい。番号の小さい順に並べ替えない。

**トラックを増やす**

クリップを、いま端にあるトラックのさらに外へドラッグしたときだけ、1本増やす。増える本数に上限は置かない。一度のドラッグで増やすのは1本までとし、戻してからもう一度外へ出すと、次の1本が増える。

- **映像** — 一番上の映像トラックにあるクリップを、さらに上へドラッグすると、その上に映像トラックを1本追加する。名前は「映像 4」「映像 5」と、下から上へ番号を増やしていく。
- **音声** — 一番下の音声トラックにあるクリップを、さらに下へドラッグすると、その下に音声トラックを1本追加する。名前は「音声 2」「音声 3」と、上から下へ番号を増やしていく。
- 素材ペインの一覧から、既存のレーンの上で離したときは、そのトラックの離した時刻にクリップを置く。種類が違うときは置かない。空き領域（一番上の映像トラックより上、または一番下の音声トラックより下）へドロップしたときは、ドラッグ中と同じ規則でトラックを1本足し、そこにクリップを置く。
- 追加したトラックにも、同じヘッダーを付ける。映像は目玉、スピーカー、鍵。音声はスピーカーと鍵。
- トラックの初期の高さは 72px。タイトル、サムネイル、波形がそれぞれ見える高さにする。トラックとトラックの境目を上下にドラッグすると、そのトラックの高さだけを変えられる。ヘッダーとレーンは同じ高さに揃える。
- トラック一覧の見出し側の一番上に「＋ 映像トラックを追加」、一番下に「＋ 音声トラックを追加」を置く。時間軸の側にはボタンを出さない。見出しと時間軸の上下の空きは同じ高さにして、縦の位置がずれないようにする。映像はいま一番上のさらに上へ、音声はいま一番下のさらに下へ足す。番号は、いまの最大より 1 大きい。

テロップは専用トラックを分けず、映像トラック上のクリップとして置く。

#### トラックエリア（メイン）

クリップを時間軸上に置く、横に長い領域。トラックヘッダーの行と、縦位置を揃える。

- トラックが増えて縦に収まらないときは、右端に縦スクロールバーを出す。
- 下端に横スクロールバーを出す。横スクロールはルーラーと一体で動かす。
- 横スクロールの左端は、時刻 0 より前へは行かない。最後のクリップの右には、画面幅か3分以上の空の時間を足した長さの余白を持たせる。右端の近くまで来たら、さらに先の空の時間へ範囲を動的に伸ばし、長い時間を左右に行き来できるようにする。
- 素材ペインからドロップしたクリップも、この空の時間帯へ置ける。

**クリップの共通操作**

- クリックすると、そのクリップだけを選択し、プレビューを `timeline` に切り替える。モニターは再生ヘッドの時刻を映す。`Shift` を押しながらクリックすると、選択に足す。もう一度 `Shift` クリックすると、そのクリップだけ選択から外す。選択中のクリップは、太い白枠と影で、ほかのクリップとすぐに見分けられる。
- クリップをダブルクリックすると、再生ヘッドをそのクリップの開始時刻へ移動する。2回目の押下（`detail` が 2）と、同じクリップを 450 ミリ秒以内にもう一度押したことの両方で頭出しにする。少し指がずれても、すぐにはドラッグにしない。カット比較とテロップ生成のクリップも、同じ方法で、そのタイムラインの再生ヘッドをクリップの頭へ動かす。
- 空き領域を左ドラッグすると、半透明の矩形を描く。離したとき、その枠に触れていたクリップだけをまとめて選ぶ。枠の外のクリップは選ばない。`Shift` を押したままなら、今の選択に足す。ほとんど動かさずに離したときは、再生ヘッドは動かさず、`Shift` が無いときだけ選択を外す。ドラッグの始点は、押し始めたときのタイムライン上の位置に固定する。ドラッグ中にタイムラインをスクロールしても、始点は動かず、ポインタの側だけがスクロール量の分だけ延びる。スクロールで画面の外に出た部分も、枠の中にあるクリップは選ぶ。
- 同じトラックで、クリップとクリップのあいだに 0.05 秒より長い空白があるとき、その空白をクリックすると選択できる。選択中は半透明の破線ブロックになり、右上に「×」を出す。×を押すと、その空白の長さだけ、同じトラックで空白より右にあるクリップを左へ詰める。他のトラックと再生ヘッドは動かさない。ロック中のトラックは詰めない。詰めたあとは選択を外し、タイムラインを描き直す。クリップのドラッグ、端のトリミング、吸着、プレビュー再生は、これまでどおりである。
- クリップの端は、暗い背景でも境目が分かるように、薄い境界線と少し明るい面で描く。
- 空き領域を右ドラッグすると、タイムラインを上下左右にパンする。空き領域のカーソルは掴める形、ドラッグ中は掴んでいる形にする。タイムライン上の右クリックメニューは出さない。
- 本体をドラッグして、同じトラック内、または同じ種類の別トラックへ移動する。複数選んでいるときは、選んだクリップを、マウスの移動量だけ相対的に一緒に動かす。時刻の間隔は保つ。トラックを変えたときは、選べるトラックなら同じ段数だけずらす。間のトラックを飛ばして、映像なら任意の映像トラック、音声なら任意の音声トラックへ、1回のドラッグで直接置ける。途中のトラックでドラッグが途切れない。動画・画像・テロップは映像トラック同士、音声は音声トラック同士でのみ移す。長押しでも、ブラウザのドラッグ禁止マークは出さない。
- 左右の端をドラッグして、長さを変える（トリミング）。
- 動画または画像のクリップを選ぶと、中央ペインにプロパティ編集が出る。画像、テロップ、動画の位置・大きさ・回転は、プレビュー上の直接操作でも変えられる。
- ロック中のトラックにあるクリップは、これらの操作をしない。ロック中のトラックへは移動しない。

**クリップの重なり（上書き）**

移動やトリミングで、同じトラック内の他のクリップと重なったときは、操作したクリップを優先する。下になったクリップの、重なった部分は残さない。

- 端が重なったときは、下のクリップを重なりの分だけ短くする。
- 下のクリップの途中に重なったときは、そのクリップを重なりの前と後ろに分割する。
- 操作したクリップに完全に覆われたクリップは、トラックから消す。
- 別のトラックにあるクリップは、見た目が上下に重なっても削らない。
- ドラッグの途中では上書きしない。手を離して位置と長さが確定してから、そのトラックのクリップ配列を整理する。

**ドラッグ中のプレビュー**

移動やトリミングのドラッグ中は、処理を軽くするため、プレビューの映像をシークしない。ドラッグを始めたときに映っていた画面を、そのまま維持する。

- タイムライン上のブロックは、ドラッグ中も `startTime` と `duration` に合わせて位置と幅を描き直す。
- 手を離したとき、上書きを確定したあと、その操作の時刻へプレビューを合わせる。移動と左端のトリミングはクリップの先頭、右端のトリミングはクリップの末尾とする。

**スナップ**

クリップをドラッグしているとき、他のクリップの端（開始時刻と終了時刻）、および再生ヘッドの時刻に近づくと、そこへ吸着する。移動ではクリップの両端、トリミングでは動かしている端を対象にする。吸着している間は、その時刻に細い縦のガイドを出し、離れたら消す。

#### クリップの見た目

種類ごとに、トラック上のブロックの描き方を変える。ベースカラーも種類で分ける。動画と画像は、上にファイル名、中にサムネイル、動画だけ下に波形を出す。音声は波形だけを全面に出す。

| 種類 | ベースカラー | 中身 |
|---|---|---|
| 動画 | 青緑系 | 上段にファイル名（暗い帯）、中段に先頭フレーム、下段に白い音声波形（暗い帯）。波形の上に、音量 0〜200% の水平な白い線を出す。100% が中央、200% が上端。選択中は白い二重枠 |
| 画像 | 青緑系 | 上段にファイル名、中段にその静止画。波形と音量の線は出さない |
| 音声 | 紫系 | 波形だけを、暗い背景の上に全面へ出す。サムネイルとファイル名の帯は出さない。音量の白い線は出す |
| テロップ | 青の単色 | テキストの冒頭を、クリップ名として表示する |

- サムネイルは、中段の高さに合わせて収める。極端に狭いときは、先頭が少しでも見えるようにする。
- 波形は下から伸びる棒で描く。無音に近い区間は棒が低くなる。
- 動画の下段と、音声クリップの波形を上下にドラッグすると、そのクリップの音量が 0〜200% の範囲で変わる。上へ動かすと大きく、下へ動かすと小さくなる。既定は 100%。ドラッグしているあいだは、カーソルのそばに `85%` のような今の音量を出す。手を離すと、その表示は消える。プロパティの音量と、再生中の音は、その場で同じ値になる。100% を超える大きさは、プレビューでは Web Audio のゲインで出し、書き出しでは FFmpeg の `volume` に `音量 / 100` を渡す。プレビュー全体の音量スライダーは 0〜100 のままである。
- テロップは、入りきらない文字を末尾で省略する。

#### ズーム

時間軸の拡大と縮小は、次の両方で行う。クリップの中身（秒数）は変えず、画面上の幅だけが変わる。右へ伸ばした空の時間も、同じ倍率で広げる。

- 上部ツールバー右端のズームスライダー。
- トラックエリア上での `Ctrl` + マウスホイール。ホイールを奥へ回すと拡大、手前へ回すと縮小する。

ズームの基準点は、ポインタがある時刻、または再生ヘッドの時刻にする。拡大しても、見ていた時刻が画面の外へ飛ばないようにする。

### 専用サブ編集画面

ツールペインの「カット一括削除選択」「テロップ生成」「テロップ編集」は、メイン画面の中では完結しない。押すとモーダルの専用画面を開く。決定するか閉じると、メイン編集画面に戻る。

メインのタイムラインへ戻すときの扱いは、画面ごとに分ける。

- **カット一括削除選択** — 開いたときに対象だった元クリップを、選んだ側のクリップ配列で置き換える（Replace）。元クリップ自体は残さない。
- **テロップ生成** — 元の動画クリップは消さない。確定したテロップは、その動画のすぐ上の映像トラックへ追加する。すぐ上に置けないときは、その動画の直前に新しい映像トラックを作る。下のクリップは上書きしない。
- **テロップ編集** — 開いたテロップの文言、見た目、位置、スケールを、もとのテロップクリップへ書く。

置き換えたあとの再生位置と選択は、グローバルステートの `currentTime` と `selectedClipId` を更新して、各ペインへ同期する。

#### カット一括削除選択

選択中の動画クリップを材料に、カット比較用のサブ画面を開く。無音解析の結果が無いときは、先に解析を実行し、終わってから開く。

```text
左側
  上部タイムライン（自動削除版） …… 右端に［選択して適用］
        （上下のあいだに余白）
  下部タイムライン（スプリット版） …… 右端に［選択して適用］
右側
  プレビューモニター
```

- **右側** — プレビューモニター。今アクティブな側のタイムラインだけを映す。
- **左側上部（自動削除版）** — スプリット版から無音ブロックを消し、どのトラックの有音とも重ならない無音区間だけを、全トラック共通で左へ詰める。有音が重なる無音は、そのトラックから消すが、他のトラックの時刻は動かさない。
- **左側下部（スプリット版）** — 各クリップを、元のトラックと元の開始時刻のまま、無音と有音に分ける。
- **左端の時刻** — 上下どちらのタイムラインも、左端は 00:00 固定ではない。選択した元クリップのうち、いちばん早い `startTime` を左端にする。目盛りの数字はその絶対時刻（メインタイムラインと同じ `MM:SS`）で、1秒の幅もメインタイムラインと同じである。クリップの位置は `(startTime - 左端) × メインと同じ1秒幅` で置く。
- **トラックヘッダー** — 各レーンの左に、メインと同じトラック名（映像 1、音声 1 など）を出す。上下の順はレーンと揃える。
- **クリップの見た目** — 動画は名前・サムネイル・波形、無音は斜線、テロップは青い帯で、メインタイムラインと同じ色分けにする。
- **上下の区別** — 上下は別系統のタイムラインなので、あいだに余白を置き、視覚的に離す。
- **複数トラック** — 選択した動画があるトラックだけを、メインタイムラインの上から下の順で、自動削除版とスプリット版の両方にレーンとして出す。選んでいないあいだのトラックは出さない。上下の順はメインと同じ。

**シーク**

シークは上下で独立させる。それぞれのタイムラインが、自分のシークバーと再生ヘッドを持つ。

- 自動削除版の時間軸は、無音を詰めたあとの時刻である。削除した無音の位置でシークが止まってはいけない。シークバーは、詰めたあとの先頭から終わりまでを一本の軸として動き、プレビューもその詰めた時刻の映像を出す。
- スプリット版の時間軸は、切り込みを入れた元の時刻である。無音のブロックの上も、シークは止まらずに通る。
- 操作している側（アクティブな側）の映像と音声だけが、右側のプレビューに流れる。もう一方の再生ヘッドは、その側を再びアクティブにするまでプレビューを奪わない。

**クリックと編集の分離**

上下のどちらも、最初のクリックと、そのあとの操作を分ける。

- **1回目のクリック** — クリックした側（上段または下段）をアクティブにする。右側のプレビューを、その側の再生ヘッドの時刻へ切り替える。クリックしただけでは、クリップは移動しない。
- **クリップのドラッグ** — クリップを前後にドラッグすると、その側がアクティブになり、開始時刻が動く。端をドラッグすると長さが変わる。離したとき、同じレーンで重なった部分は、動かしたクリップを残して上書きする。
- **ハサミ** — 上下どちらの再生ヘッドにも、メインと同じハサミを付ける。クリックすると、その側で再生ヘッドが通っているクリップを分割する。選択中のクリップが再生ヘッドの上にあるときはそれだけを切り、無いときはその位置のクリップを切る。ハサミを横にドラッグすると、その側の再生位置が動く。
- **ズーム** — 自動削除版とスプリット版の見出しの横に、それぞれのズームスライダーを置く。時間軸の拡大と縮小は、そのタイムラインだけに効く。
- アクティブでない側をクリックしたときは、再び「1回目」として、その側をアクティブにし、プレビューを切り替える。移動やトリミングは、その側がすでにアクティブであるときだけ行う。
- **Space** — この画面が開いているあいだ、Space はアクティブな側のプレビューを再生または一時停止する。
- **Delete / Backspace** — タイムライン上で選んでいるクリップブロックを、その側から外す。メインタイムラインの元クリップは、「選択して適用」まで残る。

**適用**

各タイムラインの右端に「選択して適用」を置く。上か下、押した側のクリップ群を確定し、レーンごとのクリップを、開いたときのトラックへ、画面上の開始時刻のまま入れ替える（Replace）。元の選択クリップは残さない。複数トラックを開いていた場合も、トラックの対応と時刻はそのまま戻す。置き換えが終わったらこの画面を閉じ、メイン画面に戻る。適用せずに「閉じる」を押したとき、または解析の途中で開くのをやめたときは、メインタイムラインのクリップと `state.project` は開く前のままにする。この画面を開くための解析は、メインのクリップを切らない。

#### テロップ生成・テロップ編集（共通レイアウト）

どちらも同じ骨組みのテロップ専用画面を開く。中身のリストだけが機能ごとに違う。

画面全体は左右に分ける（左 70% / 右 30%）。左側はさらに上下に分ける（上 70% / 下 30%）。

```text
左側 70%
  上部 70%: テロップのリスト（多いときはこの領域だけスクロール）
  下部 30%: 確認用サブタイムライン
右側 30%
  プレビューモニター
```

- **右側（30%）** — プレビューモニター。テロップを直接ドラッグして位置を動かせ、四隅でスケールも変えられる。動かした X、Y、スケールは、左の手動設定の数値へすぐ入る。数値を変えても、プレビューの枠が同じ位置と大きさになる。
- **左側上部（左領域の 70%）** — テロップをブロック単位で上から並べる。件数が多いとき、スクロールするのはこのリスト領域だけにする。画面全体やタイムラインは動かさない。
- **左側下部（左領域の 30%）** — テロップ確認用のサブタイムライン。テロップ生成では、左端を選択クリップのいちばん早い `startTime` にし、目盛りとクリップ位置はメインタイムラインと同じ時刻の幅で置く。選択した動画があるトラックごとにレーンを分け、メインと同じ上から下の順で出す。各テロップは、元の動画があるレーンの、その動画の時刻に置く。見出しの横に、このタイムラインだけのズームスライダーを置く。再生ヘッドにはハサミを付け、クリックでその位置のテロップを分割する。テロップをドラッグすると前後に動き、離すと同じレーンの重なりを上書きする。開いているあいだ、Space でプレビューを再生または一時停止する。適用せずに閉じたときは、メインのクリップと `state.project` は開く前のままにする。
- **リストとタイムラインの連動** — リストのブロックを選ぶと、下のサブタイムラインで該当クリップがハイライトされ、シークバーがその位置へ移動する。プレビューには、そのテロップがすぐ表示される。

#### テロップ生成

歯車で決めた「1文の文字数」と「文章のまとまり」を基準に、テロップを自動生成し、リストとサブタイムラインへ上から順に並べる。文字起こしがまだ無いときは、先に解析を実行し、終わってから開く。

リストとサブタイムラインへ渡す文は、選んでいる動画クリップの範囲だけにする。範囲は、各クリップのタイムライン上の `startTime` から `duration` まで（速度があるときは、素材側では `duration` に速度を掛けた長さ）に対応する素材時間である。複数の動画を選んでいるときは、最初に選んだ動画と同じ素材のクリップの範囲を合わせる。文が範囲に完全に入るときはそのまま、一部だけ重なるときは重なっている部分の時刻だけを残す。範囲の外の文は出さない。この範囲に重なる文字起こしが無いときは、画面を開かず知らせる。

各ブロックでは、次の2文を横に並べて選ぶ。

- **そのままの言葉** — 文字起こしに近い原文。
- **綺麗な正しいテロップを生成** — AIが整えた文。要約とインパクトは、カードの下のボタンで選ぶ。

選んだ文のテキスト欄をクリックすると、さらに手入力で修正できる。選択中のブロックは、共通レイアウトの連動規則に従ってタイムラインとプレビューへ反映する。

「決定して適用」は、確定した文言と時刻のテロップを、その動画クリップのすぐ上の映像トラックへ追加する。すぐ上が無いか、重なるクリップがあるときは、その動画の直前に新しい映像トラックを作る。動画クリップは残る。初期の枠は、文言の文字数と文字サイズから幅と高さを決める。文字起こしの時刻は、無音を詰めた時間からソースの時間へ戻してからタイムラインへ置く。

#### テロップ編集

開いたときにリストへ載せるテロップは、選んでいるクリップそれぞれの `startTime` から `duration` までに重なるものだけである。動画を1件選んだときは、そのクリップの長さ（トリミング後の長さ）と重なるテロップだけにする。テロップを選んだときは、そのテロップの時間範囲と重なるものだけで、重なっている動画クリップ全体や、同じトラックの全テロップは含めない。複数選んでいるときは、選んだ各範囲の和とする。

プリセットを一番少ない操作で選べるようにする。各ブロックの並びは次のとおり。

- **左** — そのテロップの文章を小さく表示する。フォント、サイズ、色、縁、太字、背景、動きに加え、スケール、X座標、Y座標を手動で指定できる。
- **右** — プレビュー。枠のドラッグで位置、四隅で大きさを変える。

ここで保存・選択したプリセット（アニメーションを含む）は、今のプロジェクト専用にしない。後述のプリセット共有により、すべてのプロジェクトから同じものを呼び出して使える。

「決定して適用」で、見た目、位置、スケールを、もとのテロップクリップへ書く。閉じただけではプロジェクトは変わらない。

## プリセット共有（全体機能）

ユーザーが作った設定を「プリセット」として保存し、今のプロジェクト以外からも呼び出せる。保存先はプロジェクトごとではなく、アプリ全体の設定として扱う。

テロップのプリセットは、専用サブ画面の「テロップ編集」で保存・選択する。アニメーションも含む。

保存できるものの例:

- テロップのフォント、大きさ、色、アニメーション
- 画像や動画の変形パラメータ（スケール、幅、高さ、位置、回転など）
